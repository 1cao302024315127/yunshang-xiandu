# 云上仙都项目需求与功能进度

项目名称：云上仙都 · 非遗数字化传承与 VR 全景云游览  
更新日期：2026-10-21  
用途：供开发人员了解当前 Demo 的功能范围、已有实现和后续待办，方便需求对接与任务拆分。

标记说明：`[x]` 表示当前项目已有对应代码或内容；`[ ]` 表示尚未完成、实现不完整或仍需确认。已勾选不等于已完成真实设备验收，涉及云服务的功能另标明联调状态。

## 一、项目概况

项目围绕仙都景区，将地图选点、全景游览、AI 讲解和非遗互动学习结合起来。当前以网页形式提供服务，主要操作流程如下：

打开导览地图 → 选择景点 → 浏览全景与讲解 → 点击热点了解非遗 → 参与问答或互动学习 → 下载海报或分享链接。

- [x] 提供无需登录即可使用的网页 Demo。
- [x] 提供桌面布局、手机窄屏布局和触屏拖动逻辑。
- [x] 内置 3 个景点、7 个场景热点、12 个非遗词条、4 个祭典步骤及 6 组文化对比。
- [x] 支持本地启动及同一局域网访问，便于电脑演示和手机联调。

## 二、功能需求与已有实现

### 1. 地图与景点选择

- [x] 首页展示仙都导览图，以景点名称、图标和标签标记可游览位置。
- [x] 点击地图标记进入对应景点，更新全景图片、讲解标题、热点及关键词列表。
- [x] 提供顶部景点切换按钮，标识当前场景，并支持返回地图重新选择。
- [x] 提供丁字桥场景，关联“古桥”“祈福”两个热点。
- [x] 提供岩拓书店场景，关联“文创”“轩辕黄帝”两个热点。
- [x] 提供黄帝祠宇场景，关联“黄帝祠宇”“祭祀”“轩辕黄帝”三个热点。
- [x] 切换景点时保留当前讲解版本和语言，清除上一个词条的选中状态并停止已有播报。

### 2. 全景浏览

- [x] 提供可旋转的全景浏览区域，支持鼠标拖动及手机滑动改变视角。
- [x] 支持水平、俯仰方向查看，限制俯仰角度，松手后有惯性滑动效果。
- [x] 空闲时缓慢自动旋转，用户拖动时暂停，惯性结束后等待约 4 秒恢复。
- [x] 进入场景时先显示低清预览及加载提示，主图加载完成后切换展示。
- [x] 场景热点随视角变化定位，显示词条名称和分类图标，视野外热点自动隐藏。
- [x] 进入景点时镜头平滑转向首个热点方向，点击热点可打开对应文化解释。
- [x] 窗口尺寸变化时调整画布；浏览器不支持全景渲染时提供提示。

当前素材：三个场景均使用普通实景照片加工出的伪全景，主图为 2048 × 1024，预览图为 512 × 256。当前具备全景交互，真实 360° 实拍素材尚未替换。

### 3. AI 景点讲解

- [x] 进入景点后加载该景点的文字讲解，面板显示景点名称和讲解内容。
- [x] 提供青少年版，侧重趣味科普、互动提问和生动比喻。
- [x] 提供中年版，侧重文化背景、历史脉络与理解分析，作为默认版本。
- [x] 提供老年版，侧重从容亲切的表达、家国情怀与文化渊源。
- [x] 支持切换讲解版本，并重新加载当前景点、当前语言下的讲解。
- [x] 已编写通义千问调用逻辑，依据景点资料、年龄风格和目标语言生成讲解。
- [x] 未配置 AI 服务或调用失败时，使用本地“开场白 + 景点正文 + 结束语”生成讲解。
- [x] 显示“本地模式”或“大模型模式”，并提供讲解加载中、加载失败提示。
- [x] 讲解中匹配到的中英文词库名称可点击，打开对应词条解释。

当前分层方式：本地模式下，三个年龄版本共用景点正文，通过不同开场白和结束语区分；大模型模式下将年龄风格加入生成要求。云服务调用代码已存在，真实服务可用性仍需联调确认。

### 4. 非遗关键词解释

- [x] 内置轩辕黄帝、祭祀、礼乐、编钟、五牲、雅乐、鼎、祈福、黄帝祠宇、鼎湖峰、古桥、文创共 12 个词条。
- [x] 词条包含名称、拼音、文化分类、核心定义、文化类比和背景延伸，并提供中英文内容。
- [x] 当前景点的热点词条以按钮形式展示，重复词条合并；点击后高亮对应按钮。
- [x] 全景热点、词条按钮和讲解正文中的关键词均可作为解释入口。
- [x] 已实现 AI 解释与本地词库解释两种路径，AI 未配置或调用失败时返回本地内容。
- [x] 获取解释后触发语音播报，也可通过“语音释义”按钮再次播放。
- [x] 关闭解释区域时停止当前播报；有文化对比数据的词条显示“文化桥”入口。

当前入口范围：面板只列出当前场景关联词条，尚未提供完整词库浏览页，因此并非全部词条都有固定可见入口。

### 5. AI 导游问答

- [x] 提供文字提问入口，支持发送按钮与回车提交；输入框当前最多输入 120 个字符，不提交空白问题。
- [x] 按对话形式展示游客提问与导游回答，等待时显示占位内容，新消息出现后滚动到底部。
- [x] 已实现依据词库知识调用 AI 回答的逻辑，生成要求包含使用所选语言、避免编造史实及未知时说明不知道。
- [x] 未使用 AI 服务时，按问题中的中文词条名称匹配，返回对应定义和类比。
- [x] 本地未匹配到词条时给出引导文案；获取回答后触发语音播报。

当前问答为单轮处理，页面可展示多条消息，但模型没有接收历史对话上下文；聊天记录未持久保存。本地模式尚不支持按英文、日文或韩文词名检索。

### 6. 语音与虚拟导游

- [x] 提供景点讲解播放入口，并复用语音功能播报词条、问答、祭典步骤及器物介绍。
- [x] 已实现讯飞语音合成调用和音频播放逻辑，中英文可走该路径；真实服务效果待联调。
- [x] 讯飞未配置或合成失败时尝试浏览器原生语音；日语、韩语直接使用浏览器语音。
- [x] 浏览器播报时按目标语言优先选择匹配的系统音色。
- [x] 播报时展示仙鹤形象、说话动画和简短内容气泡，正常结束后延时隐藏。
- [x] 返回地图、切换景点或关闭词条解释时，调用停止播报并隐藏仙鹤形象。

当前限制：独立“停止”按钮虽有停止逻辑，但初始隐藏且未接入播放状态切换，尚不能标记为完整可用。浏览器语音的音色和离线能力取决于实际设备。

### 7. 非遗测验与祭典流程

- [x] 提供非遗知识测验弹窗，每轮随机抽取 5 个不重复词条，题型为词条文化分类选择题。
- [x] 每题由正确分类及 3 个不同的干扰分类组成，并随机排列选项。
- [x] 作答后显示正确、错误反馈，禁止同题重复点击，短暂等待后自动进入下一题。
- [x] 展示答题进度和最终答对数量，并支持“再来一次”重新抽题。
- [x] 提供祭典流程时间线，按“击鼓鸣钟 → 恭读祭文 → 敬献五牲 → 乐舞告祭”展示四个步骤。
- [x] 点击祭典步骤可展开说明并触发语音，同一时刻最多展开一个步骤，再次点击可收起。

### 8. 文化桥对比

- [x] 在存在对比数据的词条解释中显示入口，打开对应的中外文化对照内容。
- [x] 已配置祭祀、礼乐、轩辕黄帝、编钟、鼎、古桥六组文化对比。
- [x] 对比内容按“起源、功能、形式、当代表达”四个维度展示两侧说明。
- [x] 提供中英文对比数据，并对手机窄屏采用纵向排列，便于阅读。

当前类比对象依次为：感恩节 / 天主教弥撒、西方宫廷礼仪 / 教堂圣乐、宙斯 / 罗慕路斯、管风琴 / 钟琴、王冠 / 权杖、佛罗伦萨老桥。该内容是 Demo 中的学习类比，具体表述仍需文化资料核对。

### 9. 3D 器物互动

- [x] 提供编钟和鼎两个器物标签，切换后更新模型并标识选中状态。
- [x] 支持鼠标、触屏拖动旋转查看器物，松手后恢复自动旋转。
- [x] 区分拖动与短按，短按触发合成音效，并播报所选器物的定义和类比。
- [x] 打开器物弹窗及窗口尺寸变化时调整展示画布。

当前编钟、鼎使用程序化几何示意模型，音效为合成声，尚未提供真实器物扫描模型或实录声音。

### 10. 海报生成与分享

- [x] 根据当前景点生成 600 × 900 竖版海报，包含背景、项目品牌、主题文案、景点名称、图标及访问地址。
- [x] 在弹窗中预览海报；场景图片加载失败时使用渐变背景继续生成。
- [x] 提供 PNG 下载，文件名包含当前景点名称。
- [x] 支持浏览器系统分享；不支持系统分享但可访问剪贴板时，复制当前页面链接。

当前“分享”发送的是页面链接，海报需单独下载。海报没有二维码，链接未携带景点位置；景点名称可按语言展示，但固定宣传文案仍为中文。

### 11. 多语言与页面布局

- [x] 提供中文、英文、日文、韩文四个语言入口，并有主要按钮和提示文案的翻译。
- [x] 已编写按当前语言刷新地图、景点按钮、年龄选项、关键词和讲解的逻辑；切换过程中的已知问题见下节。
- [x] 本地内容缺少目标语言时，优先回退英文，再回退中文。
- [x] 桌面采用全景主视区与右侧讲解面板，手机窄屏将讲解面板调整至底部，长内容可滚动。
- [x] 提供讲解面板收起操作，以及测验、祭典、文化桥、器物、海报弹窗的关闭按钮和遮罩关闭操作。

当前本地景点、词条、年龄模板、祭典和文化对比主要为中英双语，日语、韩语内容尚未完整补齐；部分固定标题和器物标签仍为中文。

## 三、待补充与完善

以下为当前已有功能的缺口或联调事项，不代表已完成。

- [ ] **停止播报按钮**：播放时显示“停止”，结束后恢复按钮状态，使主动停止入口可见、可用。
- [ ] **讲解面板重新展开**：收起后保留独立的展开入口，避免必须返回地图才能恢复。
- [ ] **语言切换异常**：修复操作提示自动移除后，语言切换仍访问该元素的问题。
- [ ] **语言切换内容同步**：刷新已经打开的词条解释、祭典和文化对比内容，避免新旧语言混用；补齐现有固定中文界面文案。
- [ ] **日韩语内容**：补充日文、韩文景点讲解、词条和互动内容；保留回退时，应明确提示实际展示语言。
- [ ] **连续操作结果一致**：快速切换景点、讲解版本或词条时，只保留最后一次选择的结果，防止较早请求覆盖当前内容。
- [ ] **语音切换与失败处理**：新播报开始前停止旧音频；停止后不再播放迟到的合成结果，并处理无音色、播放失败等状态。
- [ ] **完整词库入口**：提供主动浏览全部 12 个词条的入口，使未关联场景热点的词条和文化对比也可被找到。
- [ ] **弹窗关闭后的任务清理**：清理测验跳题定时器、相关播报等，避免关闭后继续触发交互。
- [ ] **素材失败提示**：全景图片或器物展示加载失败时给出明确说明，并保留可继续操作的入口。
- [ ] **分享反馈**：补充复制成功、取消分享、分享失败或当前浏览器不支持时的提示。
- [ ] **真实云服务联调**：使用实际配置检查 AI 讲解、词条解释、自由问答和讯飞播报，记录成功及降级表现。
- [ ] **目标设备联调**：在电脑、手机及微信内置浏览器中确认触屏操作、面板遮挡、语音和图片下载体验。
- [ ] **文化与素材核对**：确认照片对应景点、讲解史实、祭典步骤及文化类比表述，并补充相应资料来源。
