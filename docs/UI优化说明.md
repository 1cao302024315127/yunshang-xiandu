# 云上仙都 UI 优化说明

更新日期：2026-10-23。基线提交：`7519f26`。

本次沿用 Flask 与原生 HTML/CSS/JS，将首页调整为简洁的景点与文化导览。保留主视觉中的“一程山水，千年回响”，其余栏目与操作采用客观、明确的表达。

## 界面调整

- [x] 首页按“景点介绍、非遗文化、导览地图”组织内容，手机端也直接显示导航。
- [x] 移除微小英文装饰标题、侧边题字、印章、宣传脚注、重复特色介绍和卡片分类标签。
- [x] 首页正文使用 17–18px，导航、按钮和功能说明使用 16–17px。讲解、释义及问答正文使用 17px，模式等辅助文字为 15px。
- [x] 三张景点卡片保留名称、客观简介与“查看景点”入口；文化区保留词库、祭典和器物入口。
- [x] 手机地图使用编号标记和独立的景点名称按钮，避免名称随 SVG 缩小；注明位置仅供示意。
- [x] 手机场景导航支持横向滚动，当前景点自动保持可见，长英文名称不再拆成碎字。
- [x] 中英日韩首页文案同步精简；三种讲解版本的开场与结语改为简短说明，AI 讲解提示同步要求客观表达。
- [x] 海报移除装饰英文、编号、印章与宣传结语，保留景点照片、名称和导览信息。
- [x] 保留全景、地图、讲解版本、词库、语音、问答、测验、祭典、跨文化对比、3D 器物与海报等原有交互。

## 代码位置与素材边界

- `static/index.html`：首页结构、导航、场景与弹窗。
- `static/css/editorial.css`：当前视觉、字号与响应式布局；`style.css` 保留基础组件与动画，并设置 17px 基础字号。
- `static/js/home.js`：四语言首页文案、景点卡片和地图名称入口。
- `static/js/app.js`：场景导航、讲解标签、SVG 标记和海报绘制。
- `data/guides.json`、`app.py`：讲解模板及生成风格提示。
