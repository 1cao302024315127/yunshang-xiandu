# 云上仙都 UI 优化说明

更新日期：2026-10-23。

本次在现有 Flask + 原生 HTML/CSS/JS 项目中完成界面改版。首页采用米白、黛绿和少量朱红，使用本地宋体及系统字体、统一线性图标和项目已有照片，不新增前端框架或远程字体依赖。

## 类似项目与本次取舍

| 参考项目 | 可核实的特点 | 本项目采用的设计方向 |
| --- | --- | --- |
| [全景故宫](https://pano.dpm.org.cn/)，[故宫官方数字平台介绍](https://www.dpm.org.cn/bottom/platform.html) | 提供建筑全景浏览与线上游览入口。 | 将导览首页与沉浸场景分开，保留明确的选景、返回和讲解入口。 |
| [数字敦煌](https://www.e-dunhuang.com/index.htm) | 按经典洞窟、壁画等内容组织数字文化资源，提供浏览及介绍。 | 将三个现有景点整理为照片卡片，并为词库、祭典、器物提供独立入口。 |
| [Visit Finland：Things to do](https://www.visitfinland.com/en/things-to-do/) | 以自然、文化及活动主题组织旅行内容。 | 首页先展示山水与旅行主题，再引导选择景点；自然风景与文化体验分区呈现。 |

表中第三列是本次针对现有项目作出的设计选择。上述项目的图片、代码及品牌素材均未引入本项目。

## 代码位置

- `static/index.html`：首页结构、图标、场景布局和弹窗标识。
- `static/css/editorial.css`：新版视觉和响应式覆盖层，加载在原 `style.css` 之后。
- `static/js/home.js`：首页文案、照片卡片、导航及原有功能入口。
- `static/js/app.js`：衔接首页与现有场景流程，面板状态、释义定位及海报绘制。
- `static/js/artifact3d.js`：器物展示背景及环境光亮度。

## 查看方式

双击项目根目录的 `启动.bat`，或运行 `python app.py`，在浏览器打开 `http://127.0.0.1:5000`。如果页面仍显示旧版，使用 Ctrl + F5 刷新。
