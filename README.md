# 云上仙都 · 非遗数字化传承与 VR 全景云游览

> 浙江工业大学「运河杯」大学生课外学术科技基金项目 —— 立项作品
> 作品名称：云上仙都·非遗数字化传承与VR全景云游览AI智能服务项目

一套以缙云仙都景区为试点的「非遗 + AI」云游览系统，实现 **360° VR 全景漫游**、
**千人千面的 AI 导游讲解**、**非遗文化「关键词溯源」** 三大核心能力。

---

## 一、功能对照（与申报书设想）

| 申报书模块 | 本仓库实现 | 状态 |
|---|---|---|
| 仙都全景 VR 漫游（360° 自由视角） | 自研轻量 WebGL 等距柱状全景引擎，拖拽/滑动/自动旋转，热点交互 | ✅ 已实现（占位全景图） |
| 基于游客画像的 AI 多模态导游（青少年/中年/老年） | 年龄标签驱动分层导游词，大模型/本地模板双模式 | ✅ 已实现（已接通义千问 qwen-plus，无网自动降级本地模板） |
| 非遗文化「关键词溯源」（祭祀、礼乐、轩辕黄帝…） | 本地非遗词库 + 跨文化类比释义，点击热点/词条即溯源 | ✅ 已实现（10 个核心词条） |
| 多语种、多音色语音播报（讯飞 TTS） | 讯飞 TTS 接口预留 + 浏览器原生语音兜底 | ✅ 已实现（默认浏览器语音，可接讯飞） |
| 双端（Web + 微信小程序） | 响应式 H5（手机微信内置浏览器可直接打开） | ✅ Web 端；小程序见「待办」 |

## 二、技术栈

- **后端**：Python 3 + Flask（标准库实现大模型/语音调用，无额外重依赖）
- **前端**：原生 HTML/CSS/JS（响应式 H5）
- **全景渲染**：自研 WebGL 等距柱状全景引擎（零外部依赖，离线可用；可平滑替换为 Three.js/Krpano）
- **AI**：阿里通义千问（DashScope，OpenAI 兼容接口）—— 已接通；未配置/断网时走本地模板兜底
- **语音**：科大讯飞语音合成（新版 WebSocket v2，HMAC-SHA256 鉴权）—— 已接通；未配置时走浏览器原生 TTS

## 四、快速开始

```bash
cd yunshang-xiandu
pip install -r requirements.txt   # 只需 Flask
python app.py
```

浏览器打开 **http://127.0.0.1:5000**（Windows 也可直接双击 `启动.bat`）。

> 手机同局域网访问：后端已 `host=0.0.0.0`，手机访问 `http://<电脑IP>:5000` 即可（微信内置浏览器直接打开即演示）。

## 五、接入真实 AI（拿到 Key 后，改 `config.json` 即可，代码零改动）

### 1. 阿里通义千问（导游词 + 关键词溯源）
1. 登录 [阿里云百炼平台](https://bailian.console.aliyun.com/)，开通模型服务，创建 **API-KEY**；
2. 填入 `config.json` 的 `dashscope_api_key`（模型默认 `qwen-plus`，可换 `qwen-max`/`qwen-flash`；注意本账号下 `qwen-turbo` 已停用/限流）；
3. 重启后端，健康检查 `GET /api/health` 的 `llm_enabled` 变为 `true`，讲解词进入「大模型模式」。

### 2. 科大讯飞 TTS（语音合成，WebSocket v2）
1. 注册 [讯飞开放平台](https://www.xfyun.cn/)，创建应用并开通「在线语音合成」；
2. 将 `APPID`、`APIKey`、`APISecret` 填入 `config.json` 的 `iflytek` 字段（`voice_name` 可选 `xiaoyan`/`aisjiuxu` 等）；
3. 需 `pip install websocket-client`（已在 `requirements.txt`）；
4. 重启后端后，`/api/tts` 返回 `mode: "audio"`，前端自动播放讯飞合成音频。

> 自检：`python scripts/check_keys.py` 会实测讯飞 TTS，返回音频字节数即表示接通。

> **兜底机制**：两处 Key 均未配置时，系统自动降级为「本地预制三版导游词模板 + 浏览器原生语音合成」，**离线也能完整跑通「点击热点 → 生成讲解 → 语音播报」闭环**，保证答辩演示稳定。

## 六、替换真实仙都全景图

实拍/官方授权全景图拿到后，只需：
1. 把等距柱状（2:1，如 4096×2048）全景图覆盖到 `static/assets/panoramas/` 下的同名文件；
2. 如需增删场景或热点，编辑 `data/scenes.json`（`panorama` 字段指向图片，`hotspots` 里 `yaw`/`pitch` 为热点在 360° 空间中的方位角/俯仰角）。

无需改任何代码。

## 七、当前占位 / 兜底项（答辩口径）

- **全景图**：当前为程序生成的占位图（`scripts/generate_panoramas.py`），待替换仙都实拍素材；
- **AI 导游词**：未配置 Key 时用本地模板（三版风格已分层），配置通义千问后为大模型实时生成；
- **语音**：未配置 Key 时用浏览器原生 TTS（离线、多语种），配置讯飞后为讯飞音色；
- **微信小程序**：当前为响应式 H5，微信内置浏览器可直接演示；原生小程序（含 `web-view` 壳）见下方待办。

## 八、待办 / 后续可扩展
